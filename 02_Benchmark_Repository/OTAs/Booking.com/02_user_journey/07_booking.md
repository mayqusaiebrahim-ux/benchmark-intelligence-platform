# Step 07 — Booking
**Company:** Booking.com | **Benchmark #4**

## Summary
The Booking.com booking flow is standard OTA structure: select room type, review policies, proceed to checkout. The AI presence is minimal at this stage — the "Perfect for a 4-night stay!" signal from Step 05 (Recommendations) was the pre-booking AI moment; the flow itself does not add AI intelligence.

One observation: the Genius loyalty program discount was surfaced during availability check — a logged-in user would see pricing adjusted for their loyalty tier. This is personalization rather than AI, but it is a relevant contrast point to Saudia's Alfursan program.

No AI upsell, no AI-powered room comparison, no contextual upgrade recommendation, and no dynamic pricing explanation was observed in the public booking flow.
